# kelompok-limkop

Website Profil Resmi **Kelompok Limkop** ("Sang Oposisi").
Lahir dari meja warkop Lima Kopi.

## Tech Stack
- **Framework:** React 18 + Vite 5
- **Styling:** Tailwind CSS (Apple Cupertino Dark Theme)
- **Animation:** Framer Motion
- **Icons:** Lucide React

## Menjalankan Proyek
```bash
# Install dependencies
npm install

# Jalankan server development
npm run dev

# Build untuk produksi
npm run build
```
